# MetroCity College Database Project

## Project Overview

The MetroCity College Database Project is designed to manage student, course,
enrollment, and exam score information.

The database system was developed, tested, and documented as part of the
Database Design and Implementation module. This project also uses Git and
GitHub for version control and project file management.

## Project Objectives

The main objectives of this project are:

- Manage student information
- Manage course information
- Record student enrollments
- Store exam score information
- Maintain clear database documentation
- Use Git and GitHub for version control
- Prepare the project for future maintenance and collaboration

## Database Description

The MetroCity College database stores academic information using related
database tables.

The main tables are:

### Student
Stores student information such as:
- Student ID
- First name
- Last name
- Email
- Phone
- Department

### Course
Stores course information such as:
- Course ID
- Course code
- Course title
- Credits
- Department

### Enrollment
Stores student enrollment information such as:
- Enrollment ID
- Student ID
- Course ID
- Term
- Enrollment status

### ExamScore
Stores exam score information such as:
- Score ID
- Enrollment ID
- Exam type
- Score
- Score date

## Main Features

- Store and manage student records
- Store and manage course records
- Connect students and courses through enrollment records
- Store exam results
- Use primary and foreign keys to maintain relationships
- Support SQL operations and database testing
- Provide database documentation and a data dictionary
